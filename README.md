# 🎮 PlayStation Store — Bootstrap

Projeto de uma página inspirada na PlayStation Store, desenvolvido como exercício prático para estudar e aplicar os recursos do **Bootstrap 5**.

## 📋 Sobre o projeto

A página apresenta uma seleção de jogos esportivos, utilizando componentes e classes do Bootstrap para construir uma interface responsiva e organizada.

O projeto foi desenvolvido com foco no aprendizado de:

- Sistema de grid do Bootstrap
- Cards
- Navbar responsiva
- Dropdown
- Modal
- Badges
- Botões
- Containers
- Responsividade
- Utilitários de espaçamento, cores e tipografia

## 🚀 Tecnologias utilizadas

- HTML5
- Bootstrap 5.3
- CSS através das classes e utilitários do Bootstrap

> Não foi utilizado JavaScript próprio no projeto. O JavaScript incluído é apenas o `bootstrap.bundle.min.js`, necessário para componentes nativos do Bootstrap, como Navbar, Dropdown e Modal.

## 🕹️ Funcionalidades

- Navbar responsiva
- Menu dropdown de ofertas
- Seção de novidades
- Catálogo de jogos esportivos
- Cards responsivos
- Informações de preço
- Botões de compra
- Seção de ofertas
- Modal de assinaturas
- Layout adaptado para diferentes tamanhos de tela
